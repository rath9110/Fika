# Fika Project Rules & Guidelines

This directory contains the core design and engineering principles for the Fika app. All AI agents must review and adhere to these guidelines when modifying the codebase.

## 🏛️ Core Foundations
- [tech-stack.md](./tech-stack.md) - React, Vite, TS, Capacitor, Supabase.
- [data-and-state.md](./data-and-state.md) - Offline-first, localStorage prioritize, sync logic.
- [management-and-process.md](./management-and-process.md) - Port management and development workflows.

## 🎨 UI & UX Standards
- [visual-hierarchy.md](./visual-hierarchy.md) - Typography, spacing, and button priority.
- [mobile-first.md](./mobile-first.md) - Touch targets (44px+), no-hover UX, bottom nav.
- [animation-and-motion.md](./animation-and-motion.md) - Subtle easing, swipe thresholds.

## ✍️ Communication
- [tone-and-copy.md](./tone-and-copy.md) - Gentle, human phrasing; no "First Name Last Name" formality.
